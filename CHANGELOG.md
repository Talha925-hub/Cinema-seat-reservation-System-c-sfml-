# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-02-02

### Added
- Initial release of Cinema Seat Reservation System
- Movie selection interface
- Seat booking with VIP/Regular options
- Concessions menu (drinks & popcorn)
- Payment system with card validation (16-digit)
- Automatic bill generation
- Multi-screen GUI navigation
- Data persistence (movie-wise file storage)
- Real-time seat availability updates
- Click-based intuitive interface

### Technical Details
- Built with C++ and SFML
- Object-Oriented Architecture
- File-based database
- Cross-platform compatibility

### Known Limitations
- Single-user interface
- File-based storage (not suitable for large scale)
- Basic payment validation

## Format

### Types of Changes
- **Added** for new features.
- **Changed** for changes in existing functionality.
- **Deprecated** for soon-to-be removed features.
- **Removed** for now removed features.
- **Fixed** for any bug fixes.
- **Security** in case of security vulnerabilities.
