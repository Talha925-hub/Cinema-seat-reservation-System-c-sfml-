# Cinema-seat-reservation-System-c-sfml-
🎬 Cinema Seat Reservation System in C++ using SFML — a GUI app for full movie booking flow. Users select a movie, choose VIP/normal seats, add drinks &amp; popcorn, and pay by cash/card (16-digit check). • Auto bill • Click-based UI • Multi-screen navigation • Saves reservations to movie-wise files.
